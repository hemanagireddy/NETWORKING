# NETWORKING

Types 

PAN — Personal Area Network
LAN — Local Area Network
MAN — Metropolitan Area Network
WAN — Wide Area Network

 OSI Model Layers

Physical — Transmits raw bits
Data Link — Transfers frames between connected devices
Network — Handles logical addressing and routing
Transport — Provides end-to-end transport
Session — Manages communication sessions
Presentation — Handles data representation and encryption
Application — Provides network services to applications

IP Address


An IP address identifies a device or network interface for communication.
which are 

IPv4
IPv6
Public IP
Private IP

Dynamic IP
